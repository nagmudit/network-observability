How to capture

  1. Start recording here.
  2. Reload the inspected page so initial requests are visible.
  3. Use the website while keeping DevTools open.
  4. Open requests in the local viewer to inspect their headers and bodies.

Only this inspected tab is observed. Bodies are saved after requests finish, up to 128 KiB each (or a smaller gateway limit). Infinite streams, WebSocket frames, unavailable browser bodies, desktop apps, and VS Code are not captured by this connector. Sensitive headers are redacted; bodies and URLs may contain private data.
